# શુભ વિવાહ કંકોતરી – Animated React Invitation

React + Vite + Framer Motion. Suspense gate → press-and-hold the seal → doors open → animated pages.

## Run
    npm install
    npm run dev        # http://localhost:5173

## Build / deploy
    npm run build      # output in dist/  (upload to Vercel / Netlify / any static host)

## Customise
Edit invitation details and all Gujarati/English copy in `src/data.js`. Use the language switch in the top-right corner to preview either version; both Sanskrit shlokas are kept unchanged in Sanskrit. Page layouts are in `src/components/Pages.jsx`. Colours are CSS variables at the top of `src/styles.css`.
